# Community skills

Community skills now live in a separate repo: [PostHog/community-skills](https://github.com/PostHog/community-skills).

Please don't add new skills to `skills/community/` in this repo (`PostHog/skills`). Add them to `PostHog/community-skills` instead.

To share a skill with the PostHog community, either:

- Publish it from the community skills store in PostHog, or
- Open a pull request in [PostHog/community-skills](https://github.com/PostHog/community-skills). Its [contributing guide](https://github.com/PostHog/community-skills/blob/main/CONTRIBUTING.md) explains the folder layout and the `SKILL.md` frontmatter.
